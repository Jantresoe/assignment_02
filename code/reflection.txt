When I first did the assignment, I felt confident, but it turned out to be more difficult than expected. i struggled a lot with coding the __init__.py because I was so used to my code being in one singular page and being able to access it freely, so it was very difficult experience learning how to organize a project so that different files and grams have separate responsibilities. That is why, in the later moments, I was unable to find the problem within my coding because I was mainly focused on a single page and ignoring the other connecting code. Thankfully, the integration test allowed me to see not which of my code was wrong but how I got it wrong, from the wording to even the wrong function to use. The process became much easier, and I even became a little more proficient at reading my code and seeing exactly what went wrong, even in the most inconspicuous of places. Overall, the assignment taught me that understanding how different parts of a program work together is just as important as understanding the individual code itself.
